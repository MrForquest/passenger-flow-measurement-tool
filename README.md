# Passenger Flow Measurement Tool

Flask REST API для прогнозирования пассажиропотока на станциях Московского метро. Модель принимает дату, час, линию и название станции и возвращает предсказанное количество пассажиров вместе с процентом загруженности относительно вместимости станции.

## Как это работает

Предсказание строит CatBoost Regressor. На вход модель получает 8 признаков: закодированное название станции и линии, час, день недели, признак праздничного дня, сезон, месяц и день. Праздники определяются через российский производственный календарь (`isdayoff`), результаты кэшируются на весь 2023 год при старте сервера.

Загруженность считается как `prediction / capacity * 100`. Значения `capacity` для каждой станции захардкожены в `data.py` и представляют собой усреднённые исторические данные.

## API

### `GET /stations/?date=YYYY-MM-DD&hour=H`

Возвращает список всех станций с их текущей загруженностью.

```json
[
  { "id": 9, "loadedPercentage": 87 },
  { "id": 14, "loadedPercentage": 112 }
]
```

### `GET /stations/<station_id>/?date=YYYY-MM-DD&hour=H`

Детальная информация по конкретной станции: имя, загруженность в указанный час и почасовой график на весь день (с 5:00 до 23:00).

```json
{
  "id": 9,
  "name": "Охотный ряд",
  "loadedPercentage": 87,
  "commentaries": [],
  "graphicInfo": [[5, 1200], [6, 3400], ...]
}
```

## Запуск

```bash
cd backend
pip install -r requirements.txt
python server.py
```

Сервер поднимается на `http://localhost:5000`.

## Стек

- Python 3.x
- Flask 2.3 + Flask-CORS
- CatBoost 1.2
- scikit-learn (LabelEncoder)
- isdayoff (российский производственный календарь)
- pandas, numpy
